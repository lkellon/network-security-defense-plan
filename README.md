# Network Security Defense Plan

## Overview

This project presents a defense-in-depth network security plan for a modern organization. It was developed from academic work completed in a University of Maryland Global Campus Network Security course and reorganized as a cybersecurity portfolio project.

The plan evaluates multiple attack paths and recommends layered administrative and technical controls to reduce risk, improve detection, and strengthen recovery.

## Security Areas Addressed

- Unauthorized network intrusion
- SQL injection
- Cross-site scripting (XSS)
- Phishing and credential theft
- Malware and ransomware
- Firewall configuration and network segmentation
- Intrusion detection and prevention (IDPS)
- Multifactor authentication and access control
- HTTPS/TLS and encryption
- Secure web application practices
- Patch management
- Endpoint protection
- Backup and recovery
- Centralized logging and monitoring
- Vulnerability assessment
- Incident response

## Security Approach

The project uses a defense-in-depth strategy rather than relying on a single security control.

### 1. Asset Identification & Risk Assessment
Inventory systems, applications, network devices, wireless access points, data, and user accounts. Identify critical assets, threats, vulnerabilities, and potential business impact.

### 2. Preventive Controls
Implement least-privilege firewall rules, network segmentation, secure wireless configurations, MFA, endpoint protection, encryption, HTTPS/TLS, secure backups, and patch management.

### 3. Application Security
Reduce SQL injection and XSS risks through parameterized queries, input validation, output encoding, secure development practices, security testing, and Content Security Policy.

### 4. Detection & Response
Monitor IDPS alerts, authentication logs, endpoint events, firewall logs, and application logs while establishing procedures for investigation, escalation, and system isolation.

### 5. Continuous Improvement
Perform vulnerability scanning, penetration testing, phishing exercises, access reviews, backup restoration testing, and incident-response exercises.
