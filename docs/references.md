# References & Security Guidance

The following authoritative cybersecurity resources were used in the original academic project and informed the security recommendations presented in this repository.

## Cybersecurity and Infrastructure Security Agency (CISA)

Cybersecurity and Infrastructure Security Agency.  
**#StopRansomware Guide**

Guidance related to ransomware prevention, multifactor authentication, identity and access management, and organizational resilience.

## National Institute of Standards and Technology (NIST)

McKay, K. A., & Cooper, D. A. (2019).  
**Guidelines for the Selection, Configuration, and Use of Transport Layer Security (TLS) Implementations**  
NIST Special Publication 800-52 Revision 2.

Used for TLS and secure web communication concepts.

Scarfone, K., & Mell, P. (2007).  
**Guide to Intrusion Detection and Prevention Systems (IDPS)**  
NIST Special Publication 800-94.

Used for intrusion detection, monitoring, event analysis, and intrusion-prevention concepts.

## OWASP Foundation

**SQL Injection**

Used to research SQL injection attacks and secure database-query practices.

**Cross Site Scripting (XSS)**

Used to research cross-site scripting vulnerabilities and mitigation techniques.

**Web Security Testing Guide — Test HTTP Methods**

Used for HTTP GET/POST and web security testing concepts.

**Web Security Testing Guide — Testing for SQL Server**

Used for SQL injection testing and input-validation concepts.

---

## Portfolio Note

These references were used as part of the original academic research for this project. Cybersecurity guidance changes over time, so current official NIST, CISA, and OWASP publications should be consulted when applying these concepts to production environments.
